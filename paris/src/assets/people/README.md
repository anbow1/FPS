# Postacie z Blendera (MPFB)

Tu trafia wynik `tools/people/build_people_mpfb.py`: `<postać>_full.bin/.json`,
`<postać>_far.bin/.json` i folder `tex/`. Gdy folder ma postacie, tłum
bulwaru używa ich zamiast proceduralnych sylwetek (`life/humanMesh.ts`);
`&people=builds` w adresie wraca do proceduralnych. Tekstury i siatki
pochodzą z MakeHuman system assets (CC0).
