# Plan dla PC z RTX 5090 (Blender 5.2), krok po kroku

Co robisz na PC, w jakiej kolejności i co mi odesłać. Każdy krok ma oznaczenie:

- **GOTOWE** — możesz to zrobić od razu, wszystko jest w repo;
- **CZEKA** — najpierw muszę coś dopisać w kontenerze (napiszę, kiedy będzie gotowe).

Komendy są dla PowerShella, z głównego folderu repo (`C:\Users\bigbo\Documents\AI\FPS`).

## 0. Przygotowanie (raz)

1. `git pull origin main` — przed każdym krokiem.
2. Zainstalowane: Blender 5.2, Node 22 (`node -v`), ffmpeg w `PATH` (`ffmpeg -version`).
3. W PowerShellu, na początku każdej sesji:
   ```powershell
   $B = "C:\Program Files\Blender Foundation\Blender 5.2\blender.exe"
   ```
4. W Blenderze: *Edit → Preferences → System → Cycles Render Devices → OptiX*, zaznaczona 5090.

## 1. Pomiar wydajności na prawdziwym GPU — GOTOWE (~15 min)

Po co: wszystko sprawdzam w programowym rendererze, więc nie znam prawdziwych czasów klatki.
Ten pomiar mówi, ile zapasu jest na droższe efekty (cienie wszystkich latarni, światło odbite,
gęstsza roślinność) i na jakich ustawieniach je włączać.

Dla każdej gry: Field Line, Castaway Lagoon, Tanks.

```powershell
cd field-line; npm install; npm run build; npx vite preview --port 4173
```

1. Otwórz `http://localhost:4173/` w Chrome, wejdź do gry na jakości *High*.
2. Pauza (Esc) → *Benchmark*. Gra sama obejdzie stałe punkty mapy.
3. Zrób zrzut ekranu tabeli wyników.
4. Powtórz na *Low* i dla nocy w City (Field Line: mapa *City*, światło *Night*).
5. Zamknij serwer (Ctrl+C), `cd ..`, to samo dla `castaway-lagoon` i `tanks`.

**Odeślij:** zrzuty tabel (gra, mapa, jakość, pora dnia) i rozdzielczość monitora.

## 2. Postacie z MPFB w nowym szkielecie — GOTOWE (~20 min)

Po co: szkielet gry ma już 21 kości (kręgosłup, szyja, obojczyki, palce stóp), a animacje są
przenoszone z pozy A. Postacie trzeba przebudować nową wersją skryptu, inaczej zostają stare.

Wymaga: MPFB 2.0.x z extensions.blender.org i paczki *MakeHuman system assets*
(w MPFB: *Apply assets → Load pack*).

```powershell
cd paris\tools\people
& $B -b --python build_people_mpfb.py '--' --list
& $B -b --python build_people_mpfb.py '--' --out out --preview
cd ..\..\..
Copy-Item -Force paris\tools\people\out\*.bin, paris\tools\people\out\*.json paris\src\assets\people\
Copy-Item -Force paris\tools\people\out\tex\* paris\src\assets\people\tex\
git add paris/src/assets/people; git commit -m "Rebuild MPFB people on the 21-bone skeleton"; git push origin main
```

**Sprawdź:** `paris\tools\people\out\preview\*.png` — każda postać w ubraniu, z włosami,
bez dziur na łokciach i kolanach.
**Odeślij:** wynik `--list` (cały tekst), jeśli którejś postaci brakuje ubrania albo fryzury.

## 3. Stroje dla gier (żołnierze, partyzanci) — GOTOWE pobranie, CZEKA budowa

Po co: w Field Line i Lagunie zastąpić obecne modele ludźmi z MPFB.

1. **GOTOWE:** z makehumancommunity.org (licencja CC0 albo CC-BY) pobierz i wgraj do MPFB
   (*Apply assets → Load pack* albo do folderu assetów MPFB):
   - Field Line: mundur polowy (bluza + spodnie), kamizelka taktyczna, hełm, plecak, buty wojskowe;
   - Laguna: koszulka, spodnie bojówki, chusta albo czapka, sandały lub buty robocze.
2. Uruchom `--list` jak w kroku 2 i **odeślij wynik** — po nim dopiszę obsady `--cast fieldline`
   i `--cast lagoon`.
3. **CZEKA:** gdy napiszę, że obsady są gotowe:
   ```powershell
   cd paris\tools\people
   & $B -b --python build_people_mpfb.py '--' --cast fieldline --out out_fl --preview
   & $B -b --python build_people_mpfb.py '--' --cast lagoon --out out_lg --preview
   ```
   Foldery `out_fl` i `out_lg` — gdzie je skopiować, napiszę razem z obsadami.

## 4. Pojazdy z gotowych modeli — GOTOWE (~10 min na model)

Po co: auta na bulwarze i w City są dziś kanciaste i proceduralne; to największa widoczna różnica
od zdjęć.

**Szukanie:** Sketchfab, filtr *Downloadable*, licencja *CC Attribution* albo *CC0*, format glTF,
50–300 tys. trójkątów, tekstury PBR. Bez znaczków i nazw marek (albo do zdjęcia w Blenderze).

| 2 | sedan (też jako taksówka) | 4.70 | Field Line, Paryż |
| 3 | kombi | 4.60 | Paryż |
| 4 | furgonetka dostawcza | 5.00 | Field Line, Paryż |
| 5 | wrak osobówki (spalony) | 4.30 | Field Line |
| 6 | pickup | 5.30 | Field Line |
| 7 | ciężarówka skrzyniowa | 7.50 | Field Line |
| 8 | czołg podstawowy (długość z lufą) | 9.70 | Tanks |
| 9 | BWP | 6.80 | Tanks |
| 10 | ciężarówka wojskowa | 8.00 | Tanks |
| 11 | autobus miejski | 12.00 | Paryż |

Dla każdego modelu (przykład dla hatchbacka):

```powershell
& $B -b --python paris\tools\vehicles\prepare_vehicle.py '--' C:\modele\hatchback.glb --out shared\vehicles\hatchback --length 4.05 --forward -y --preview
```

1. **Sprawdź** `shared\vehicles\hatchback\hatchback_preview.png`: przód w prawo w dół kadru, koła
   na ziemi. Jeśli przód patrzy gdzie indziej, powtórz z `--forward x`, `-x` albo `y`.
2. Jeśli koła lub światła się nie wydzieliły (w logu skryptu), podaj ich nazwy z Blendera:
   `--wheels "nazwa_koła"`, `--lights "nazwa_świateł"`.
3. **Wpisz** do `shared\vehicles\hatchback\hatchback.json` pola `author`, `url`, `license`.
4. `git add shared/vehicles; git commit -m "Add hatchback model"; git push origin main`

Wystarczą pierwsze trzy modele, żebym zaczął wczytywanie w grach; resztę dosyłaj po kolei.

## 5. Cienie otoczenia (AO) budynków Field Line — CZEKA

Po co: miękkie przyciemnienie w narożnikach, pod gzymsami i balkonami — dziś budynki są
oświetlone zbyt równo.

1. **CZEKA:** dopiszę `field-line/tools/bake/export_city.mjs` (zapis geometrii mapy do `.glb`)
   i `bake_ao.py` (Cycles, OptiX, wynik w mapach AO).
2. Potem na PC (komendy dostaniesz razem ze skryptami, mniej więcej tak):
   ```powershell
   cd field-line; node tools\bake\export_city.mjs city out\bake\city.glb
   & $B -b --python tools\bake\bake_ao.py '--' out\bake\city.glb --out src\assets\ao --samples 512
   ```
3. **Sprawdź** podgląd `src\assets\ao\city_preview.png` i wypchnij folder `src/assets/ao`.

## 6. Impostory drzew na dalekie plany — CZEKA

Po co: drzewa daleko jako zdjęcia z 8–16 stron, wyrenderowane w Cycles (las Field Line,
dżungla Laguny, platany bulwaru). Mniej trójkątów i lepsze światło w koronach.

**CZEKA** na `tools/bake/bake_impostors.py`; potem jedno uruchomienie na gatunek drzewa.

## 7. Mapy normalnych z modeli high-poly — CZEKA

Po co: skały, rekwizyty i broń z detalem, którego nie da się wymodelować w niskiej siatce.
**CZEKA** na listę modeli (z Poly Haven i z pętli krytyków) i skrypt `bake_normals.py`.

## 8. Film Paryża — GOTOWE (~10 min)

```powershell
cd paris; npm install; npm run build; Start-Process npx "vite preview --port 4180"
node scripts\record.mjs http://localhost:4180/ out 1920 1080 ffmpeg 2 gpu
```

**Odeślij:** plik z `paris\out` (albo link do niego).

## Nowe zadania z pętli krytyków

Pętla porównań ze zdjęciami (Laguna, Field Line, Tanks, na końcu Paryż) może dorzucić rzeczy,
których kontener nie zrobi sam (np. konkretne modele albo wypalenia). Dopiszę je tutaj jako
kolejne kroki, z tym samym oznaczeniem GOTOWE / CZEKA.
