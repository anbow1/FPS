# Photographed ground

Scanned PBR texture sets from [Poly Haven](https://polyhaven.com), released
under the [Creative Commons CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/)
public domain dedication. Attribution is not required; it is given here as a
courtesy. Resized to 512 px and re-encoded as JPEG: colour, normal (OpenGL
convention), ORM (AO, roughness, metalness) and height.

| Folder              | Source                                   | Used for                    |
| ------------------- | ---------------------------------------- | --------------------------- |
| `sparse_grass/`     | https://polyhaven.com/a/sparse_grass     | the meadow floor            |
| `stony_dirt_path/`  | https://polyhaven.com/a/stony_dirt_path  | dry soil, tracks and verges |
| `rock_face_03/`     | https://polyhaven.com/a/rock_face_03     | granite on steep ground     |
| `muddy_tracks/`     | https://polyhaven.com/a/muddy_tracks     | wet mud                     |
