# Photographed textures

Scanned PBR texture sets from [Poly Haven](https://polyhaven.com), released
under the
[Creative Commons CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/)
public domain dedication. Attribution is not required; it is given here as a
courtesy. Resized to 512 px and re-encoded for the game (JPEG): colour, an ORM
map (AO, roughness, metalness) and a height map, from which the game derives
the normals.

| Folder                     | Source                                            | Used for                                  |
| -------------------------- | ------------------------------------------------- | ----------------------------------------- |
| `brick_wall_02/`           | https://polyhaven.com/a/brick_wall_02             | brick walls and façades                   |
| `red_brick_03/`            | https://polyhaven.com/a/red_brick_03              | dark brick walls and façades              |
| `concrete_floor_worn_001/` | https://polyhaven.com/a/concrete_floor_worn_001   | concrete walls and kerbs                  |
| `forest_ground_04/`        | https://polyhaven.com/a/forest_ground_04          | the forest's dirt tracks                  |
