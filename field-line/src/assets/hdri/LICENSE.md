# HDR environments

HDRIs from [Poly Haven](https://polyhaven.com), released under the
[Creative Commons CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/)
public domain dedication. Attribution is not required; it is given here as a
courtesy. Prepared for the game offline (`render/hdri.ts`): the 1k file
averaged down to 512 × 256, the sun disc cut out (the game's directional light
carries the sun) and written as flat RGBE.
